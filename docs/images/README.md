## Image Guidelines

- **Format:** PNG preferred (supports transparency)
- **Quality:** High-resolution, but optimized for web (<500KB per image)
- **Aspect ratio:** Maintain consistency across screenshots
- **Annotations:** Add arrows, highlights, or callouts where helpful
- **Branding:** Use MediAI gradient colors (#667eea → #764ba2)

## Screenshot Tips

### Taking Screenshots

1. **Use browser developer tools** to ensure consistent viewport size
2. **Hide personal information** (use demo data)
3. **Ensure good contrast** for readability
4. **Capture full page** or relevant section only

### Recommended Tools

- **macOS:** Cmd+Shift+4 (region), Cmd+Shift+3 (full screen)
- **Windows:** Windows+Shift+S (Snipping Tool)
- **Linux:** Flameshot, GNOME Screenshot
- **Browser:** Chrome DevTools (Ctrl+Shift+P → "Capture screenshot")

### Image Editing

- **Annotations:** Snagit, Skitch, or Preview (macOS)
- **Diagrams:** Draw.io, Lucidchart, Excalidraw
- **Optimization:** TinyPNG, ImageOptim
